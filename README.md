# Pragya Sharma - Portfolio

## Edit
- All content (links, projects, skills, posters, Canva link) is in `data.js`.
- Photo: replace `images/profile.jpg`.
- Resume: replace `resume.pdf`.
- Posters: add images to `images/posters/`, then add a line in `POSTERS` in `data.js`.
- Project images (optional): add to `images/projects/` and set `image` in `data.js`.

## Put it online (free)
1. Create a new GitHub repository (example name: `portfolio`) and upload all these files to it.
2. Go to vercel.com, sign in with GitHub, click "Add New Project", pick the repo, click Deploy.
3. Your link will look like `your-project.vercel.app`. Every change you push to GitHub updates the site.

## Preview on your computer
Double-click `index.html`.
